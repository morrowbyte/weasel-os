Lumi is the original generated weasel included with the desktop companion.
The source atlas was generated for this project with Imagegen on 2026-11-10.
The build normalizes its 4 by 8 grid to 256-pixel cells without changing the
pose ordering. All animation strips settle after four frames; there is no
permanent idle animation. Runtime privacy gestures remain native-controlled.

Custom packs use the same pet.json and RGBA PNG format. They contain artwork
only; no script, URL, or executable asset is loaded.
